Why image file size matters for your website

Images typically account for 50–70% of a web page's total file size. Every extra kilobyte makes the page slower to load, and page speed has direct, measurable consequences:

  • Google ranking: Page speed is a confirmed Google ranking factor, especially on mobile. Google PageSpeed Insights specifically flags oversized images as a critical issue.
  • Bounce rate: Studies consistently show that pages taking longer than 3 seconds to load see dramatically higher abandonment rates.
  • Core Web Vitals: Google's LCP (Largest Contentful Paint) metric — which directly affects Search ranking — is usually the main hero image on a page. If it's a 2MB PNG, your LCP score will be poor.
  • Bandwidth costs: If you're on a hosting plan with bandwidth limits, bloated images can significantly increase your costs.

The good news: image optimisation is one of the highest-ROI improvements you can make to a website, and modern tools make it easy.

Method 1: Convert to a more efficient format — the biggest single impact

The single most effective way to reduce image file size for a website is to use the right format. In 2026, that means WebP for virtually all web images.

Why WebP?

  • WebP lossy is 25–34% smaller than JPEG at equivalent quality
  • WebP lossless is 26% smaller than PNG
  • WebP supports transparency (no need for PNG in most cases) and animation
  • Supported by 96%+ of browsers in 2026
  • Recommended by Google PageSpeed Insights and Lighthouse

Method 2: Use the right quality settings

Both JPG and WebP use a quality scale (usually 0–100). Higher quality = larger file. The key insight is that most people set quality too high:

  • JPG quality 85 is visually identical to 100 for most photos at standard web sizes, but significantly smaller
  • WebP quality 80 is typically indistinguishable from quality 90–95 on most web displays

For most web images, quality settings between 75–85 deliver the best balance of file size and visual quality. Anything above 90 results in diminishing returns — larger files with no visible benefit to users.

Method 3: Resize dimensions to match your display size

A very common mistake: uploading a 4000×3000 pixel image from a camera and displaying it at 800×600 on a web page. The browser scales it down, but the browser still downloads all 4000×3000 pixels.

Before optimising format and quality, make sure your image dimensions match your intended display size. A 4000px wide image serving a 800px wide blog post column is carrying 25x more data than needed.

Practical guide:

  • Full-width hero images: 1440–1920px wide maximum
  • Blog post inline images: 800–1200px wide
  • Product thumbnails: 400–600px
  • Icons and logos: Only as large as needed (often under 200px)

Method 4: Add lazy loading to images below the fold

Lazy loading tells the browser to only load images when the user scrolls near them — instead of loading every image on page load. It's a one-line HTML change with a significant impact on perceived load time:

<img src="image.webp" alt="Description" loading="lazy">

Don't add loading="lazy" to your above-the-fold hero image — that actually makes it slower. Apply it to everything else.

Quick image optimisation checklist

  • ☑ Convert all web images to WebP format
  • ☑ Set quality to 75–85 (not 100)
  • ☑ Resize dimensions to match display size — don't serve 4K images in 800px columns
  • ☑ Add loading="lazy" to all below-the-fold images
  • ☑ Add descriptive alt text to every image (also required for SEO)
  • ☑ Serve responsive images using the srcset attribute for different screen sizes
  • ☑ Run Google PageSpeed Insights to verify improvements

Frequently Asked Questions

How do I reduce image file size without losing quality?

Convert to WebP format — it produces files 25–34% smaller than JPEG and 26% smaller than PNG at equivalent visual quality. Use img-vert.web.app to convert free in your browser.

What image format produces the smallest file size for websites?

WebP produces the smallest files for web use in 2026, supported by 96%+ of browsers. AVIF can be even smaller but has less consistent support and slower encoding times.

How do I make an image smaller in KB?

The three levers are: (1) convert to a more efficient format like WebP, (2) lower the quality setting, (3) reduce the pixel dimensions. For web images, converting to WebP usually gives the most improvement without any visible quality loss.

My image is too large to send by email — what should I do?

Convert to JPG (if it's a PNG) and reduce dimensions. Most email clients struggle with images above 1MB. For a photo from a modern camera, resize to 1200px wide and save as JPG at quality 80 — this usually gets files under 200KB. Use img-vert's PNG to JPG converter if needed.

Does converting to WebP affect image quality?

WebP lossy conversion causes a minor quality reduction — similar to JPEG at the same quality setting. At quality 80–85, the difference is invisible to the human eye on standard displays. WebP lossless conversion is pixel-perfect with no quality loss.
