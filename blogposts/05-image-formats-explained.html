JPG / JPEG — the universal photo format

Created: 1992  |  Full name: Joint Photographic Experts Group  |  Extension: .jpg or .jpeg (identical)

JPG is the most widely used image format in the world. It uses lossy compression — it achieves small file sizes by permanently discarding some image data. For photographs, this trade-off is almost always invisible to the human eye.

Key characteristics

  • Lossy compression: each save degrades quality slightly
  • No transparency support — always has a solid background
  • Excellent for photographs and complex colour gradients
  • Creates visible artefacts on text, sharp edges, and graphics at lower quality settings
  • Universally supported everywhere — browsers, phones, printers, software

When to use JPG

Photographs, product images, blog post images, social media posts, anything without a transparent background where file size matters.

PNG — lossless quality with transparency

Created: 1996  |  Full name: Portable Network Graphics  |  Extension: .png

PNG was created as an open alternative to GIF, with the key addition of full alpha channel transparency. It uses lossless compression — every pixel is preserved exactly. This makes PNG perfect for graphics that need to stay sharp, but results in large files for photographs.

Key characteristics

  • Lossless compression — no quality loss ever
  • Full alpha channel transparency (pixels can be partially transparent)
  • Larger files than JPG for photographic content
  • Excellent for logos, icons, UI elements, screenshots, diagrams
  • Does not support animation

When to use PNG

Logos, icons with transparent backgrounds, screenshots, technical diagrams, text-heavy images, any image that will be edited further.

WebP — the modern web standard

Created: 2010 by Google  |  Extension: .webp  |  Browser support: 96%+ (2026)

WebP was designed specifically for the web. It offers both lossy and lossless compression modes, supports transparency and animation, and produces files significantly smaller than equivalent JPG or PNG.

Key characteristics

  • Lossy WebP: 25–34% smaller than equivalent JPEG quality
  • Lossless WebP: 26% smaller than equivalent PNG
  • Full alpha transparency support
  • Animation support (superior to GIF)
  • Recommended by Google PageSpeed Insights
  • 96%+ browser support as of 2026

When to use WebP

All web images in 2026. WebP should be the default choice for any image displayed in a browser. Use JPG or PNG only when compatibility with older software or print workflows requires it.

GIF — animations and simple graphics

Created: 1987 by CompuServe  |  Full name: Graphics Interchange Format  |  Extension: .gif

GIF is one of the oldest web image formats, still heavily used for short animations — reaction GIFs, loading spinners, simple demos. Its compression is lossless but it's limited to 256 colours, making it poor for photographs.

Key characteristics

  • Limited to 256 colours — terrible for photos, fine for simple graphics
  • Supports basic transparency (binary — fully transparent or fully opaque, no partial)
  • Supports animation — its main remaining use case
  • Very large file sizes for animations compared to WebP or video

When to use GIF

Short web animations where video would be overkill. For new projects, consider WebP animation or a short MP4 video instead — both are significantly smaller files.

BMP — Windows legacy format

Created: Early 1990s by Microsoft  |  Full name: Bitmap  |  Extension: .bmp

BMP is an uncompressed raster format from Microsoft's early Windows era. Files are enormous — often 10–50x larger than equivalent JPG files — because no compression is applied. There is almost no reason to use BMP for web or sharing purposes today.

Key characteristics

  • No compression — pixel data stored raw, resulting in massive file sizes
  • Lossless quality (because nothing is discarded)
  • Widely supported by Windows applications
  • No web browser support (browsers can display BMP but it's not recommended)

When to use BMP

Rarely. BMP may be required by legacy Windows software or specific industrial/technical applications. For virtually everything else, convert to JPG, PNG, or WebP.

TIFF — the professional print standard

Created: 1986  |  Full name: Tagged Image File Format  |  Extension: .tif or .tiff

TIFF is the standard format in professional photography, print publishing, and document scanning. It supports high bit depths, multiple colour spaces, and lossless compression — exactly what's needed for professional workflows. TIFF files are large by design: quality is prioritised over size.

Key characteristics

  • Lossless compression — no quality loss
  • Supports very high bit depths (8-bit, 16-bit, 32-bit per channel)
  • Multiple colour space support including CMYK (required for print)
  • Can embed multiple images or pages in a single file
  • Not supported by web browsers for display
  • Very large file sizes

When to use TIFF

Professional photo editing, print publishing, document archiving, scanning workflows. Not appropriate for web use — convert to JPG or WebP first.

HEIC / HEIF — iPhone's space-saving format

Created: 2015 (adopted by Apple in iOS 11, 2017)  |  Full name: High Efficiency Image Container  |  Extension: .heic or .heif

HEIC is Apple's default camera format on iPhones and iPads since 2017. It achieves roughly 50% smaller files than equivalent JPEG quality using HEVC (H.265) compression. The trade-off: poor compatibility with Windows and non-Apple software.

Key characteristics

  • Approximately 50% smaller file size than equivalent JPEG
  • Lossless and lossy modes available
  • Supports transparency, depth maps, and multiple images in one file
  • Poor Windows support — requires a paid codec to open natively
  • Not supported by most web browsers or non-Apple devices without conversion

When to use HEIC

On Apple devices, for storage. For sharing, emailing, or posting online — convert to JPG or PNG first.

Which image format should you use?

For web publishing: WebP first, always. Fall back to JPG for photos and PNG for graphics if WebP isn't an option.

For email: JPG for photos (small, universal), PNG for logos and graphics with transparency.

For print: TIFF for professional work; JPG at high quality (95+) for casual printing.

For professional editing: TIFF, RAW, or PSD — formats that preserve maximum quality.

For iPhone photos on Windows: Convert HEIC to JPG before sharing or transferring.
