The problem with most online image converters

Search for "free image converter" and you'll find dozens of tools. Most of them work the same way: you click upload, your file travels across the internet to a server in an unknown location, the server converts it, you download the result, and somewhere in that process — your photo, your screenshot, your document scan — has been processed on a stranger's computer.

What happens to uploaded files after conversion? The privacy policies of most free converter tools are vague at best. Files may be:

  • Stored on the server for hours, days, or indefinitely
  • Accessible to the company's staff or contractors
  • Used to train AI models or analysed for other commercial purposes
  • Exposed in a data breach if the service has poor security

For most images, this may not matter. But for personal photos, business documents, medical images, IDs, financial records, or any image containing sensitive information — the upload model is a genuine privacy risk.

There's a better way.

How browser-based image conversion works

Modern browsers are extraordinarily capable. The same JavaScript and WebAssembly technology that powers complex web applications can also perform image format conversion entirely within the browser — no server required.

Here's what happens when you convert an image on img-vert.web.app:

  1. You select your file — the browser reads it from your local storage using the File API. The file data stays on your device.
  2. The browser processes it — JavaScript and the Canvas API (or WebAssembly-compiled image libraries) perform the format conversion using your computer's processor.
  3. The result is generated locally — the converted file is created in your browser's memory.
  4. You download it — your browser saves the converted file to your device, the same way any download works.

At no point in this process does any data leave your device. There is no network request containing your image. No server receives or stores anything. The entire operation is local.

Is browser-based conversion as good as server-based?

For the formats supported by img-vert (JPG, PNG, WebP, GIF, BMP, TIFF, HEIC), yes — the output quality is equivalent. The conversion algorithms are the same whether they run on your device or a server.

Modern devices — even mid-range phones — have more than enough processing power for image format conversion. Conversion is typically complete in under a second for standard photos.

Why privacy matters for image conversion — real scenarios

Personal photos

HEIC photos from your iPhone contain metadata including the date, time, and GPS location where the photo was taken. When you upload a HEIC photo to convert it, you're potentially sending that location data — along with the image itself — to an unknown server.

Business documents

Scanned invoices, contracts, employee records, and financial statements are frequently saved as images. Uploading these to a free converter means transmitting sensitive business data off your network.

Medical images

X-rays, MRI scans, and other medical images are protected by privacy laws in most jurisdictions. Using an upload-based converter with medical images may violate compliance requirements.

ID documents

Passport photos, driving licence scans, and identity documents should never be uploaded to a service whose data practices you can't verify.

Yes — img-vert.web.app. All conversions happen locally in your browser using JavaScript. Your files are never transmitted to any server.

How does browser-based image conversion work?

Your browser uses the JavaScript Canvas API and WebAssembly to process image files directly on your device. The conversion reads your file, processes it locally, and generates the output — all without any network requests containing your image data.

Is img-vert really free?

Yes, completely free. No account, no sign-up, no watermarks, no file size limits for standard formats.

Does it work offline?

Once the page is loaded, conversions work without an active internet connection. The page needs to load initially, but once loaded, the JavaScript runs entirely locally and does not require network access to perform conversions.

What is the maximum file size supported?

File size limits depend on your device's available memory rather than any server limit (because there's no server). Most modern devices handle files up to several hundred MB without issues.

Does converting images in the browser affect quality?

No. Browser-based conversion uses the same algorithms as server-based tools. The output quality is identical.
